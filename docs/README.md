# Documentation Directory

This folder contains project documentation, design artifacts, presentations, and reports for the Road Monitor project.

## Structure

- project-report/: Academic and technical reports detailing system design, methodology, and evaluation.
- diagrams/: System architecture, data flow diagrams, database schemas, and hardware setup illustrations.
- presentation/: Slides, demo decks, and presentation materials.
- screenshots/: UI screenshots, live sensor dashboards, and field deployment captures.
- ndroid-app.zip: Archived standalone build bundle of the Android data logger application.
